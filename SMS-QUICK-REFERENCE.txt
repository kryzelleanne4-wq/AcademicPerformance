│ 1. CONFIGURE CREDENTIALS                                           │
└────────────────────────────────────────────────────────────────────┘
   File: sms/function/sms-service.php
   Lines: 34-35
   
   Change:
   $this->username = $username ?? 'YOUR_SMS_GATEWAY_USERNAME';
   $this->password = $password ?? 'YOUR_SMS_GATEWAY_PASSWORD';
   
   To your actual SMS Gateway app credentials.

│ 2. TEST YOUR SETUP                                                 │
└────────────────────────────────────────────────────────────────────┘
   Command: php sms/test-sms.php
   
   This checks if credentials are configured correctly.

┌────────────────────────────────────────────────────────────────────┐
│ 3. SET UP AUTOMATED REMINDERS                                      │
└────────────────────────────────────────────────────────────────────┘
   Windows: 
   - Run: sms/cron/setup-windows-task.bat (as administrator)
   - Or manually create task in Task Scheduler
   
   Linux/Mac:
   - crontab -e
   - Add: 0 18 * * * php /path/to/sms/cron/schedule-reminder.php

┌────────────────────────────────────────────────────────────────────┐
│ 4. FEATURES                                                        │
└────────────────────────────────────────────────────────────────────┘
   ✓ Schedule Reminders - Sent 1 day before class (automatic)
   ✓ Grade Notifications - Sent when instructor saves grades (automatic)
   ✓ Admin Dashboard - View logs and send test SMS
   
┌────────────────────────────────────────────────────────────────────┐
│ 5. HOW IT WORKS                                                    │
└────────────────────────────────────────────────────────────────────┘
   Schedule Reminders:
   - Cron job runs daily at 6:00 PM
   - Checks tomorrow's schedule for each student
   - Sends SMS to students with classes tomorrow
   
   Grade Notifications:
   - Integrated into grades.php
   - Automatically sends SMS when instructor saves grades
   - Only sends to students with phone numbers

┌────────────────────────────────────────────────────────────────────┐

   - View notification statistics
   - Send test SMS
   - Manually trigger schedule reminders
   - View recent notification logs
   - Clear logs

┌────────────────────────────────────────────────────────────────────┐
│ 9. TROUBLESHOOTING                                                 │
└────────────────────────────────────────────────────────────────────┘
   No SMS sent?
   ✓ Check credentials in sms/function/sms-service.php
   ✓ Ensure SMS Gateway app is running on your phone
   ✓ Verify phone has signal
   ✓ Check students have valid phone numbers
   
   Schedule reminder not working?
   ✓ Verify Task Scheduler task is enabled (Windows)
   ✓ Check crontab entry (Linux/Mac)
   ✓ Run manually to see output
   ✓ Check schedule format contains day names
