STEP 1: Go to Students Page
────────────────────────────

    Login as Admin → Navigate to Students


STEP 2: Click Edit Button
──────────────────────────

    Find student → Click "Edit" button in Actions column


STEP 3: Update Information
───────────────────────────

    ┌─────────────────────────────────────────────┐
    │  Edit Student Information                   │
    ├─────────────────────────────────────────────┤
    │                                             │
    │  Student ID: STU-2024-0001 (read-only)     │
    │                                             │
    │  First Name: [John________________]         │
    │  Last Name:  [Doe_________________]         │
    │  Email:      [john@test.com_______]         │
    │  Phone:      [9171234567__________] ⭐      │
    │              Format: 9XXXXXXXXX             │
    │                                             │
    │  Gender:     [Male ▼]                       │
    │  Type:       [Regular ▼]                    │
    │  Block:      [BSCS 1-A ▼]                   │
    │                                             │
    │  [Update Student]  [Cancel]                 │
    └─────────────────────────────────────────────┘


STEP 4: Save Changes
─────────────────────

    Click "Update Student" → Changes saved → Phone number active!

┃  PHONE NUMBER FORMAT                                               ┃
┗━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━┛

Recommended Format:
───────────────────

    9171234567

    • 10 digits
    • Starts with 9
    • No spaces or dashes
    • Philippine mobile number


Other Accepted Formats:
───────────────────────

    ✅ 9171234567       (recommended)
    ✅ 09171234567      (will be converted)
    ✅ 639171234567     (will be converted)
    ✅ +639171234567    (will be converted)

    All formats are automatically converted to: +639171234567

Use Case 1: Add Phone to Existing Student
──────────────────────────────────────────

    Scenario: Student Jane Smith enrolled without phone number
    
    1. Go to Students page
    2. Find Jane Smith (shows "No phone ⚠")
    3. Click "Edit"
    4. Enter phone: 9281234567
    5. Click "Update Student"
    6. ✓ Jane now shows: 9281234567 ✓
    7. Jane will receive SMS notifications


Use Case 2: Update Student's Phone
───────────────────────────────────

    Scenario: Student John Doe changed phone number
    
    1. Go to Students page
    2. Find John Doe
    3. Click "Edit"
    4. Update phone: 9051234567
    5. Click "Update Student"
    6. ✓ Phone updated, SMS will use new number


Use Case 3: Bulk Phone Number Entry
────────────────────────────────────

    Scenario: Multiple students need phone numbers
    
    Alert shows: "5 active student(s) don't have phone numbers"
    
    For each student with ⚠ warning:
    1. Click "Edit"
    2. Enter phone number
    3. Click "Update"
    4. Move to next student
    
    Alert updates automatically as you add numbers
