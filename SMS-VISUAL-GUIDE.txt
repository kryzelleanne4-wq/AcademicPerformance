STEP 1: Configure Credentials (2 minutes)
─────────────────────────────────────────

    File: sms/function/sms-service.php
    Lines: 34-35

    BEFORE:
    ┌─────────────────────────────────────────────────┐
    │ $this->username = 'YOUR_SMS_GATEWAY_USERNAME';  │
    │ $this->password = 'YOUR_SMS_GATEWAY_PASSWORD';  │
    └─────────────────────────────────────────────────┘

    AFTER:
    ┌─────────────────────────────────────────────────┐
    │ $this->username = 'your_actual_username';       │
    │ $this->password = 'your_actual_password';       │
    └─────────────────────────────────────────────────┘


STEP 2: Test Configuration (1 minute)
─────────────────────────────────────

    Command: php sms/test-sms.php

    ✓ Should show: "SMS Gateway credentials configured"
    ✗ Should NOT show: "WARNING: credentials not configured"


STEP 3: Set Up Automation (2 minutes)
─────────────────────────────────────

    WINDOWS:
    ┌─────────────────────────────────────────────────┐
    │ 1. Right-click: sms/cron/setup-windows-task.bat│
    │ 2. Select: "Run as administrator"              │
    │ 3. Done!                                        │
    └─────────────────────────────────────────────────┘

    OR use: SMS-QUICK-START.bat (option 3)

    │ 2. Edit each student                            │

PROBLEM: No SMS received
────────────────────────

    Check:
    ✓ SMS Gateway app running on phone?
    ✓ Phone has cellular signal?
    ✓ Credentials correct in sms-service.php?
    ✓ Student phone number valid (9XXXXXXXXX)?

    Test: php sms/test-sms.php


PROBLEM: Schedule reminders not sent
────────────────────────────────────

    Check:
    ✓ Task Scheduler has task enabled?
    ✓ Schedule contains day names (MWF, Monday, etc.)?
    ✓ Students have classes tomorrow?

    Test: php sms/cron/schedule-reminder.php


PROBLEM: Grade notifications not sent
─────────────────────────────────────

    Check:
    ✓ Students have phone numbers?
    ✓ Grades were actually saved?
    ✓ Check flash message after saving

    Test: Save grades for a section with phone numbers
